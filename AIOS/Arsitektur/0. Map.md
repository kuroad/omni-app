
### 🧠 Mind Map: Arsitektur Web Omni-Ensiklopedia HSR

* **📍 PUSAT: Aplikasi Web Omni-Ensiklopedia HSR**
* **1️⃣ Tumpukan Teknologi (Tech Stack)**
* **Frontend:** Next.js (App Router, SSR/ISR) + TypeScript
* **State Management:** TanStack Query (React Query)
* **UI & Styling:** Tailwind CSS + Shadcn UI
* **Animasi:** Framer Motion
* **Backend (BFF):** Node.js (Fastify / HonoJS)
* **Database (Statis):** PostgreSQL
* **Caching (Dinamis):** Redis
* **Server / Web Server:** Nginx & PM2 (Process Manager)


* **2️⃣ Aliran Data (Data Flow)**
* **Jalur Dinamis (Showcase UID)**
* *Klien* ➡️ *Ketik UID*
* *Backend* ➡️ *Cek Cache Redis*
* *(Jika Hit)* ➡️ *Kirim data langsung ke Klien*
* *(Jika Miss)* ➡️ *Fetch API Mihomo* ➡️ *Sanitasi Data* ➡️ *Simpan di Redis (TTL 10m)* ➡️ *Kirim ke Klien*


* **Jalur Statis (Lore, Skill, Item)**
* *Cron Job / Worker* ➡️ *Tarik Raw Data HSR (GitHub)*
* *ETL* ➡️ *Simpan di PostgreSQL*
* *Frontend* ➡️ *Render statis lewat Database (ISR/SSR)*




* **3️⃣ Strategi UI/UX (Estetika & Interaksi)**
* **Tema HSR:** Dark Mode (Deep Space Navy), Aksen dinamis (mengikuti Elemen/Path)
* **Gaya Visual:** Glassmorphism (`backdrop-blur`), Transparansi menu kaca
* **Animasi (*Micro-interactions*):**
* *Tilt 3D* pada kartu karakter/senjata saat di-*hover*
* *Staggered Fade-In* (muncul berurutan)
* *Shimmering Skeleton* untuk status *loading*


* **Visualisasi Data:** *Radar Chart* (Recharts) untuk stat, Warna tier relik (S/A/B/C)
* **Optimasi Aset:** *Blur-up placeholder* untuk *splash art* resolusi tinggi, tipografi mirip game (Font: Inter/DIN Pro)


* **4️⃣ Skema Infrastruktur (Deployment VPS)**
* **Eksekusi Aplikasi (PM2):**
* Frontend (Next.js) berjalan di Port lokal `3000`
* Backend (Node.js) berjalan di Port lokal `3001`


* **Pintu Gerbang (Nginx Reverse Proxy):**
* *Listen* di Port Publik `80` (HTTP)
* *Routing:* `/api/*` diteruskan ke `localhost:3001`
* *Routing:* `/*` diteruskan ke `localhost:3000`


* **Keamanan & Performa Nginx:**
* Blokir akses port internal (hanya Nginx yang menghadap publik)
* Kompresi *Gzip/Brotli* untuk memperkecil ukuran *file* JSON & aset
* *Rate Limiting* IP di Nginx (mencegah *spam request*)
